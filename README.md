# 📦 Stock Manager

Um sistema de gerenciamento de estoque desenvolvido em **Java**, com foco na aplicação de conceitos de Programação Orientada a Objetos (POO), organização de código e operações de gerenciamento de produtos.

## 🚀 Sobre o projeto

O Stock Manager é um projeto pessoal desenvolvido para praticar Java e construir uma base sólida em desenvolvimento backend.

A aplicação tem como objetivo gerenciar produtos de um estoque, permitindo operações básicas de cadastro, consulta, atualização e remoção.

## 🛠️ Tecnologias utilizadas

- Java 21
- Maven
- JUnit 5
- Git e GitHub

## ⚙️ Como executar

### Pré-requisitos

- JDK 21 ou superior
- Maven instalado

### 1. Clone o repositório

```bash
git clone https://github.com/william-grassis67/stock-manager-java.git
```

### 2. Entre na pasta

```bash
cd stock-manager-java
```

### 3. Compile o projeto

```bash
mvn clean compile
```

### 4. Execute os testes

```bash
mvn test
```
